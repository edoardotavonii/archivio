DA REVISIONARE

Approvata: entra nell'archivio alla prossima sincronizzazione. Rifiutata: viene cancellata dal vault.

AGGIUNGI ALL'ARCHIVIO

trascina un'immagine qui oppure clicca per scegliere un file

Quello che aggiungi non compare subito: lo guardo io prima che entri nell'archivio. Manda solo immagini che puoi condividere e indica la fonte.

NUOVA VOCE

trascina un'immagine qui, incollala (Ctrl+V / Cmd+V)
oppure clicca per scegliere un file

Le voci aggiunte da qui restano salvate in questo browser (finché non svuoti i dati del sito) e si possono eliminare dall'indice. Per l'archivio definitivo, condiviso ovunque, aggiungile nel file (istruzioni dentro il file stesso).
